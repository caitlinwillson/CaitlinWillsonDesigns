Note: This form uses your default email app through a mailto: link. If you do not have an email app configured on your device, the submit button may not open a message window or may prompt you to configure an email app. Your browser may also display a warning message about security concerns, since using the mailto: link involves sending data through your browser and isn't a secure method for transmitting information. But this is an assignment about demonstrating the code for a simple contact form in HTML, not information security.Don't use mailto: for a form meant for real-world use.

Instead of using the mailto: link in the form, a real-world site would use some type of secure method on the server to accept the form data.
